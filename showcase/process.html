// Development Steps

开发关键步骤

从零到完整可玩 Demo 的完整流程

01

项目初始化 & 架构设计

用 TRAE 搭建项目骨架：Phaser 3 游戏引擎 + Vite 5 构建工具。定义全局色板、字体策略、场景枚举和 depth 层级规范。 TRAE 帮助快速生成了模块化架构，包括 PixelRenderer、DialogSystem、ChoiceSystem 等核心系统。

Phaser 3 Vite 5 模块化架构
// 实证 · 仓库可验证
  • Phaser 3 + Vite 5 技术栈与构建规范 — package.json · vite.config.js
  • 分层架构：scenes/ 4 场景控制器 · systems/ 14 核心系统 · systems/render/ 12 场景渲染器 · ui/ 5 组件
  • PWA 离线优先：manifest + Service Worker 预缓存，标题页轻量壳 525ms 可交互
02

像素风渲染引擎开发

核心渲染系统 PixelRenderer：12 种场景背景的像素绘制、角色立绘加载与显示、扫描线特效、金色光晕。 TRAE 帮助实现了从纯色块填充到精美像素场景的演进，暗色底 + 金色强调的统一视觉语言。

Canvas 2D 像素美术 12 场景
// 实证 · 仓库可验证
  • 12 场景渲染器：暗色底 + 金色强调的统一视觉语言 — src/systems/render/
  • 边缘洪泛去黑底算法：BFS 沿金色轮廓识别背景，保留角色暗色衣物细节
  • 场景自适应光照：12 套独立光照参数，角色"站进"场景而非贴上画面
03

剧情数据 & 选择系统设计

214 个剧情节点、35 种结局的庞大故事树。DialogSystem 处理打字机效果对话，ChoiceSystem 处理分支选择， 每个选择影响多维属性并标记远期后果。TRAE 帮助设计了数据结构和分支逻辑。

214 节点 分支叙事 远期后果

  • 硬约束：节点 next 字段禁止回退前序节点，从机制上杜绝剧情死循环

// Key Decisions

开发过程中的关键决策

AI 辅助开发中的取舍与判断

选择 Phaser 而非纯 DOM

像素游戏需要精确的 Canvas 渲染控制和精灵管理，Phaser 提供成熟的 2D 游戏框架。

✓ 渲染性能优秀

暗色底 + 金色强调的色板

参考 Downwell 的极简配色，用深蓝黑做底、金色做强调色，营造"天生骄傲"的视觉基调。

✓ 视觉辨识度高

角色立绘而非纯像素小人

放弃传统 16x16 像素小人，改用高质量像素风立绘，视觉小说风格更有代入感。

✓ 角色表现力强

DOM + Canvas 混合渲染

UI 层用 DOM overlay 保证文字清晰和中文字体渲染，游戏层用 Canvas 保证动画流畅。

✓ 中文显示完美
// Lessons Learned

创作心得

  • 1 AI 是超级加速器，但方向感要自己把握。 TRAE 能快速实现技术方案，但游戏的设计哲学 —— "不评判选择" —— 这种核心理念必须由人来定义和坚守。
  • 2 模块化是 AI 协作的关键。 把系统拆成独立的模块（PixelRenderer、DialogSystem、ChoiceSystem），每次让 TRAE 聚焦一个模块开发，效果远好于一次性生成整个项目。
  • 3 像素美术不是简陋，是克制。 暗色调 + 金色点缀 + 扫描线，用最少的视觉元素传达最强的氛围。Less is more 在像素风格里尤其成立。
  • 4 自动化测试不可或缺。 214 个剧情节点手动测试不现实。用 TRAE 生成的 E2E 脚本自动走查所有分支，确保没有死链和错字。
  • 5 有感而发 > 追求完美。 这个项目的出发点不是"做一个好玩的游戏"，而是有感而发。选择没有对错，做出来就是最好的答案。
