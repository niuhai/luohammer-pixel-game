# 罗的十字路口 · 人生模拟器

> 一款像素风互动叙事游戏：你替老罗走完 1972–2025 的 53 年人生，在每个真实历史十字路口替他做选择，承担后果，收获属于你自己的结局。

TRAE AI 创意大赛参赛作品（生活娱乐赛道）。Phaser 3 + Vite 5，纯前端无后端，PWA 离线可玩。

## 在线体验

- **游戏本体**：https://niuhai.github.io/luohammer-pixel-game/ （手机/电脑浏览器即开即玩）
- **作品展示页**：https://niuhai.github.io/luohammer-pixel-game/showcase/ （含创作过程与方案长页）

## 内容量

| 维度 | 规模 |
|---|---|
| 剧情节点 | 214 个（6 个生命阶段，`src/data/story/` 16 个文件） |
| 结局 | 35 种（条件函数 + 优先级匹配，全部经路径模拟验证可达） |
| 天赋 | 49 个（普通/稀有/传说三档，每局 5 选 2） |
| 随机事件 | 130 个（含道德困境与远期后果链） |
| 跨周目 Meta | 4 棵技能树 × 5 级 = 20 个永久增益 |

## 技术要点

- **渲染**：Phaser 3 Canvas（pixelArt 模式）+ DOM UI 覆盖层混合渲染
- **音频**：Web Audio API 程序化合成 BGM（六阶段独立动机），无音频文件依赖
- **资源**：9 角色姿态 × 12 场景全 WebP（PNG→WebP 省 95% 体积）
- **PWA**：manifest + Service Worker（network-first），离线全链路可玩
- **质量基线**：ESLint 0 错 0 警 · 427 单测 · 214 节点静态校验 0 错 · 13 策略路径模拟 · E2E 58 项
- **工程方法**：133 轮 Loop Engineering PDCA 闭环、595+ 项修复、15 条硬约束

## 快速开始

```bash
npm install
npm run dev        # 本地开发
npm run verify     # 完整质量门：静态校验 + 单测 + 构建
npm run preview    # 预览构建产物
```

## 合规声明

本作品为虚构叙事，部分情节经过艺术加工，不代表任何真实人物或事件。游戏中的"老罗"形象为艺术化演绎，旨在探讨人生选择的主题，非人物传记。未接入任何外部付费 API；语音朗读为浏览器本地 TTS。
