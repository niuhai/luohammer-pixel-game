# UI Baseline · 选择路口序章

- 快照：UI-Q003
- 日期：2026-07-28
- 当前参考：本轮工作区版本
- 主要用户：电脑端
- 次要用户：手机端
- 主场景：标题页点击“开始游戏”→选择路口序章→进入天赋选择
- 证据等级：E1（本地生产构建、确定性关键帧、真实浏览器与自动化）
- 限制：尚无真实用户或线上行为数据；评分只用于后续同口径比较

## 创作者意图

让用户快速感知自己站在人生路口：先抵达中心，再看见五条未来，最后由“换你”把观看者变成选择者。高级感必须建立在可读性之上：文字是叙事主体，不得因降噪或氛围处理退化为装饰。
