## 实现

- 五类属性联动补齐独立标题、当前数值公式和叙事说明；不再在后台立即结算并只显示四秒 Toast。
- 联动流程改为“刚刚的选择 + 组合成立条件 + 即将生效影响 → 确认 → 实际属性前后值 → 继续原剧情”，确认前状态和后续流程保持不变。
- 32 个跨阶段后果补齐来源 flag、可读的先前选择、独立标题和兑现阶段；同一承诺在不同阶段可以展示不同回响标题。
- “往事回响”改为可暂停的连续队列，显示 `往事回响 n / total`、旧选择来源、当前影响和结果页；结果确认后才进入下一段回响或返回主线。
- 扩展共享 `ConsequenceOverlay`，支持自定义进度语义和“成立条件 / 源自先前选择”等结果上下文，同时继承六视口、焦点环、读屏模态和单次结算护栏。
- 新增五类联动与 32 个后果元数据单测，以及六视口 Toast/普通剧情框到来源—结果链的前后对照 E2E。
