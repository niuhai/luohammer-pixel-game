# R016 · 对话播放控制与已读快进状态整合

- 日期：2026-07-29
- 状态：CLOSED
- 任务：UI-016
- 周期：2026-07-28-v4.2-first
- 起点：2bb38a3

## Outcome Contract

- 可观察问题：`AUTO` 按钮与“已读·快进中”角标使用相同的右上角绝对定位，桌面重叠 1214–1818px²、手机重叠 1704px²；自动播放关闭时看不到当前文字速度，手机也没有可点击的速度入口。
- 用户结果假设：把自动播放、文字速度和已读快进整合成一个不重叠的状态控制区，并暴露准确的按钮语义，可以让玩家始终知道当前阅读模式且在桌面和手机上都能可靠切换。
- 主验收：Chromium 1440×900。
- 移动护栏：Chromium 390×844、375×812。
- 最低自动化验证：L3。
- 回退：核心路径、可读性、焦点或移动端任一退化即回退本轮改动。

- [x] auto_speed_state_visibility

## 实现

- 将说话人和阅读控制放入同一弹性标题行，移除 `AUTO` 与已读角标互相覆盖的绝对定位。
- 将阅读状态拆为“已读快进”“自动 · 开/关”“慢/中/快速”三个短标签，桌面和手机都能完整呈现。
- 新增独立的文字速度按钮，手机用户可直接点击循环切换，不再依赖键盘快捷键 S。
- 自动播放按钮补充 `aria-pressed`、动态可访问名称、状态 dataset 和 A 快捷键说明。
- 速度按钮补充动态可访问名称、slow/medium/fast 状态和 S 快捷键说明。
- 已读快进状态进入阅读控制组并使用 `role="status"`；取消透明度呼吸动画，提高稳定可读性。
- 为自动播放、速度与已读状态增加稳定对比度，同时保持 44px 触控高度。

## 验证

- 基线：桌面初始重叠 1214px²，自动开启后重叠 1818px²；手机重叠 1704px²，且不存在速度按钮。
- 改后：1440×900 与 390×844 的所有状态重叠面积均为 0。
- 自动播放初始明确显示“自动 · 关”与 `aria-pressed="false"`；A 键切换为“自动 · 开”与 `aria-pressed="true"`。
- 文字速度在自动关闭时仍显示“中速”；S 键可切到快速，手机点击可从快速切到慢速。
- 桌面/手机对话—选项交接、首个选择与阅读控制 4 条真实旅程通过，新增标题行未破坏对话高度和选择焦点。
- L3 全量通过：21 个单元测试文件、360 个单元测试、生产构建和 26 条 Chromium E2E 全部通过。
