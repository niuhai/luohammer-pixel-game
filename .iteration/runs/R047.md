# R047 · showcase 瘦身（base64→WebP，9s→1.5s）

> 日期：2026-08-01 · 类型：性能优化 · 触发依据：R046 残余风险（showcase 1337KB / 9s 加载）

## 背景

R046 修复图片 404 后，PREFLIGHT 发现 showcase 页面因 CSS 内嵌 1.2MB base64 PNG 背景图，体积 1337KB、加载 9s。这是评委第一眼看到的页面，S1 级体验阻断。

## 改动

1. **base64 背景图提取为 WebP**：
   - 从 CSS 中提取 926KB base64 PNG → 解码为独立文件
   - ffmpeg 转 WebP（质量 80）：926KB → 43.5KB（95.3% 缩减）
   - CSS 背景引用改为 `url('./screenshots/bg-pattern.webp')`
2. **部署收口**：
   - dev 8a100a5 提交 + push
   - gh-pages 535bb93 提交 + push
   - 线上验证：1337KB → 102.3KB（92.3% 缩减），9084ms → 1475ms（83.8% 缩减）

## 验证（L4 线上）

| 指标 | 改前 | 改后 | 改善 |
|---|---|---|---|
