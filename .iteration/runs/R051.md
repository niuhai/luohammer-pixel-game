# R051 语音设置浮层与试听反馈

> 日期：2026-08-03 · 类型：提交前低风险 UI 收口 · 触发依据：用户确认语音设置应作为临时浮层出现，且不侵入对话阅读

## 调整范围

- 游戏内语音设置从全屏遮罩改为右上方轻量浮层，保留对话框、人物和剧情操作区。
- 增加“试听当前语音”入口，应用朗读节奏后自动试听一次。
- 将设置分组表达为“朗读内容”和“朗读节奏”，补充“只影响朗读，不改变对话框与剧情节奏”的说明。
- 拉开四种预设的语速、音调和句间短停顿：沉稳低慢、纪录更慢更平、温和柔和、明快轻快。
- 在标题页和游戏内面板显示“当前设备语音：实际名称”；无匹配中文语音时显示“当前使用浏览器默认语音”。
- 移动端固定面板高度，中间预设列表独立滚动，关闭按钮保留独立底栏。
