## Outcome Contract

- 场景：标题主操作进入序章，序章收场后加载第一幕资源，最终交接到天赋选择。
- 用户：电脑端为主、手机端为护栏；Chromium 开发构建，三张首章资源分别注入
  1500ms / 2300ms / 3100ms 延迟，以稳定观察真实 preload 中间态。
- 创作意图：等待应该像“舞台正在布置”，让玩家知道当前处于哪一幕、正在准备什么，
  而不是看到一块泛化黑屏或在标题页被提前播报无关加载信息。
- 可观察问题：
  - 标题页尚未开始游戏时，`#ui-game-loading` 仅用 `opacity: 0` 隐藏，仍是
    `role=status` 且暴露“正在进入人生… 0%”，无障碍树提前播报不存在的等待。
  - 真实资源加载期只有一行“正在进入人生…”和细进度线，没有明确阶段、资源语义，
    进度元素也没有 `progressbar` / `aria-valuenow`。
  - 进入天赋选择后加载层依旧留在布局与无障碍树，继续暴露已结束的旧状态。
- 用户结果假设：让隐藏的游戏资源加载层完全退出无障碍树，并只在真实 preload 期间暴露准确的阶段与进度，可以避免标题页提前播报无关状态，同时让进入游戏的等待更可理解。
- 变化契约：从“全程存在的泛化状态行”变为“仅在准备故事 / 布置第一幕期间出现，
  加载结束立即退出视觉和无障碍树”的阶段化舞台装载卡。
- 重点品质维度：反馈与状态、无障碍语义、视觉层级、跨端适应性。
- 不改变：序章时间线与 `UI-FREEZE-INTRO`、首章资源列表、Phaser 重试/纹理降级、
  天赋翻牌时序及故事数据。
- 主验收：Chromium 1440×900。
- 扩展验收：桌面 1366×768、1920×1080；手机 390×844、375×812、360×800。
- 验收标准：
  - 标题页和加载完成态：`hidden=true`、`aria-hidden=true`、accessibility snapshot
    为空；
  - 真实加载态：`data-loading-stage=assets`、准确 `progressbar` 与 1–99%
    `aria-valuenow`，视觉卡片不越界；
  - 25% 里程碑播报节流，避免每个 progress event 都打断读屏。
- 最低自动化验证：L3。
- 回退：核心路径、可读性、焦点或移动端任一退化即回退本轮改动。

## 实现

- 新增 `src/ui/GameLoadingUI.js` 作为唯一加载层控制器，统一管理 `preparing`、
  `assets`、`error`、`idle` 阶段，避免 IntroScene 与 GameScene 各自直接修改 DOM。
- 显示时同步移除 `hidden`、设置 `aria-hidden=false` / `aria-busy=true`；隐藏时先
  立即退出无障碍树，再用 260ms 完成视觉淡出并恢复 `hidden`，场景 create/shutdown
  双路径幂等清理。
- 第一幕 preload 使用真实 Phaser progress；`progressbar` 提供 `aria-valuenow` /
  `aria-valuetext`，live region 只在跨越 25% 里程碑时更新。
- 加载视觉改为章节化“舞台装载卡”：阶段眉题、主状态、资源说明、6px 进度轨、
  等宽百分比与边角舞台语言；手机收窄为 340px，`prefers-reduced-motion` 下关闭
  不确定进度动画。
- 补充失败状态的安全返回文案与自动清理；新增 5 项单元契约，并把真实浏览器探针
  扩展为 1440/1366/1920/390/375/360 六视口并发矩阵。

## 验证

- 基线：标题页和天赋页均 `hidden=false` 且 accessibility snapshot 暴露陈旧
  `status`；加载中只有 generic 文本，缺少 `progressbar`。
- 改后：六档视口标题页 snapshot 均为空；加载中均为 `assets`、33%、
  `progressbar "第一幕资源准备进度"`；进入天赋后均 `hidden=true` 且 snapshot
  为空。报告：`.iteration/ui/evidence/R022/after/report.json`。
- 人工对照 1440×900 与 390×844 前后关键帧：新版卡片层级清晰、百分比和进度
  对齐，无横向越界；背景氛围保持克制，不与后续天赋翻牌争夺视觉焦点。
- 单元专项：`game-loading-ui.test.js` 5/5，覆盖初始隔离、准备态、真实进度、
  里程碑播报、淡出清理和失败态。
- L3：eslint PASS；24 个 unit 文件 / 375 项测试 PASS；production build PASS；
  Playwright 31/31 PASS。最终报告：`.iteration/ui/evidence/R022-verify.json`。
