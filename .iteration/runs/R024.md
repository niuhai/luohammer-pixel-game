## Outcome Contract

- 场景：玩家在标题页、游戏顶栏、暂停菜单与朗读设置之间切换声音、朗读内容和
  讲述风格，并在当前浏览器没有 `speechSynthesis` 时打开设置。
- 用户：电脑端为主、手机端为护栏；Chromium 六视口，另用独立浏览器上下文注入
  “无系统朗读能力”。
- 可观察问题：
  - 保存的“静音 / 完整朗读 / 温和叙事”能跨场景保留，但标题声音按钮没有当前
    状态语义，游戏顶栏和暂停菜单把 `aria-pressed` 解释成“是否静音”，与朗读
    按钮的“是否启用”相反；
  - 标题朗读入口只显示讲述风格，不显示朗读内容，玩家无法在进入面板前确认完整
    状态；
  - 无系统朗读能力时仍允许选择设备语音和点击四个试听按钮，并声称使用系统语音，
    操作没有结果也没有原因；
  - 标题朗读面板不是对话框，无焦点圈定、Escape 关闭和焦点恢复；桌面入口高度
    42px，低于本周期 44px 操作护栏。
- 用户结果假设：让标题页、游戏顶栏、暂停菜单与朗读设置共享同一组可见状态、持久化结果和读屏反馈，并在系统语音不可用时解释原因，可以减少玩家在多个声音入口之间反复确认和误操作。
- 变化契约：从“状态已保存但各入口语义相反 / 无能力仍假装可用”变为“所有入口
  同向表达当前状态与下一动作、共享播报，并对能力缺失明确禁用无效动作”。
- 重点品质维度：反馈与状态、可访问语义、跨场景一致性、移动端容量。
- 不改变：序章时间线与 `UI-FREEZE-INTRO`、音效素材、朗读内容策略、语音预设参数
  和浏览器原生语音实现。
- 主验收：Chromium 1440×900。
- 扩展验收：桌面 1366×768、1920×1080；手机 390×844、375×812、360×800。
- 验收标准：
  - 声音按钮在标题、顶栏、暂停菜单统一以 `aria-pressed=true` 表示声音开启，
    文案同时说明当前状态与下一动作；
  - 标题入口同时呈现朗读内容与讲述风格，进入游戏、暂停修改、返回标题后仍一致；
  - 所有变化进入同一个 `role=status` live region；
  - 无系统朗读时显示明确原因，语音选择和四个试听动作不可用，但朗读偏好仍可保存；
  - 标题朗读面板具备 dialog/modal 语义、焦点圈定、Escape/关闭恢复，六视口控件
    ≥44px 且不越界。
- 最低自动化验证：L3。
- 回退：核心路径、可读性、焦点或移动端任一退化即回退本轮改动。

## 实现

- 新增 `AudioControlState` 作为标题、游戏顶栏和暂停菜单的共享呈现层，统一声音、
  朗读模式、讲述风格的显示文本、`aria-label`、`aria-pressed` 与播报内容。
- `AudioSystem.getSpeechSupportInfo()` 将设备能力分为“不支持系统朗读”“可用但
  无中文语音，回退默认语音”“中文系统朗读可用”，不再把能力缺失伪装成可试听。
- 标题声音按钮和朗读入口同时显示当前状态；游戏顶栏、暂停菜单与返回标题的状态
  同步采用同一语义，变化写入共享 `#ui-audio-status`。
- 标题朗读面板升级为 `role=dialog` / `aria-modal=true`：进入后聚焦当前模式，
  Tab 圈定、Escape/关闭恢复入口焦点；面板打开时标题层 `inert`，方向提示暂时隐藏。
- 无系统朗读时保留内容模式偏好，但禁用语音下拉框和四个试听按钮，显示可操作的
  设备能力解释；中文语音可用时明确“不上传文本”。
- 桌面“更多选项”按钮高度由 42px 补齐为 44px；声音/朗读状态新增单元测试和
  六视口跨场景 E2E。
- L3 暴露两个旧测试时序竞态：加载层测试会点击正在由轻量壳接管替换的按钮，
  方向提示测试会在 7 秒展示窗口结束后才断言可见；均改为先等待对应真实状态，
  没有延长产品时序或放宽结果断言。

## 验证

- 基线：持久化本身有效，但标题声音按钮没有状态语义；游戏声音开启时顶栏和暂停
  菜单均为 `aria-pressed=false`，静音后反为 `true`；标题入口遗漏“完整”模式。
- 改后六视口从标题“静音 / 完整 / 温和叙事”出发，开启声音进入游戏，暂停菜单
  切为“静音 / 无障碍 / 明快讲述”，返回标题后文本、语义和 localStorage 全部一致。
- 无系统朗读上下文：`dialog` / modal / labelledby 成立，四个试听按钮与语音选择
  均禁用，原因包含“不支持系统朗读”；手机面板在 390×844 内，最小按钮 44px，
  焦点进入并恢复，方向提示只在面板期间隐藏。
- 视觉复核：桌面入口没有挤压，暂停菜单层级保持；手机无系统朗读面板移除了方向
  提示叠压，状态说明和关闭动作完整可达。
- 专项报告：`.iteration/ui/evidence/R024/after/report.json`，六视口旅程 PASS；
  朗读面板、暂停菜单和标题产品信息既有专项回归 PASS。
- L3：eslint PASS；25 个 unit 文件 / 381 项测试 PASS；production build PASS；
