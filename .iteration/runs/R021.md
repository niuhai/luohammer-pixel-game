## Outcome Contract

- 场景：首次或离线回访进入标题页，并从标题主操作交接到序章/继续游戏。
- 用户：电脑端为主，手机端为护栏；Chromium production build，冷缓存与
  120ms RTT / 250KiB/s 下载网络。
- 创作意图：舞台和人生选择应先于引擎出现，让等待从“黑箱阻塞”变成“标题已经
  可以回应，完整体验正在接管”。
- 可观察问题：
  - 弱网基线直到 4089ms 才出现可操作标题，`DOMContentLoaded` 为 3857ms；
    标题可交互前请求 3 项、483980B。
  - Phaser 压缩传输 326053B（构建原始约 1.48MB），请求 353ms 开始、2255ms
    完成，但仍需等待引擎初始化与 BootScene 创建，标题 DOM 虽已写在 HTML 中却
    被 Loading 层遮挡且按钮为空。
  - 离线基线可以显示主按钮，但截图仍停留在“准备好了”阻塞层，且旧探针没有证明
    离线点击后能真正进入序章。
- 用户结果假设：让可操作的标题 DOM 在约 1.48MB Phaser 包下载和初始化之前独立就绪，并在标题空闲期或明确游玩意图后完成引擎接管，可以显著缩短弱网首次可操作等待，同时不牺牲开场、返回玩家和离线链路。
- 变化契约：从“等待 Phaser 完成后标题才回应”到“标题主操作先回应，点击意图被
  保留并由引擎无缝接管”。
- 重点品质维度：感知性能、反馈与状态、跨端适应性。
- 不改变：序章演出与 `UI-FREEZE-INTRO`、存档校验语义、离线完整游戏能力、
  既有标题舞台构图与品牌语言。
- 主验收：Chromium 1440×900。
- 扩展验收：桌面 1366×768、1920×1080；手机 390×844、375×812、360×800。
- 桌面验收：弱网标题可交互时间低于基线 50%，且发生在 Phaser 请求之前；点击
  100ms 内出现忙碌反馈并最终进入序章/继续流程。
- 移动护栏：主按钮 ≥44px、无横向越界；轻量壳与引擎接管前后均保留主视觉和
  核心操作。
- 最低自动化验证：L3。
- 回退：核心路径、可读性、焦点或移动端任一退化即回退本轮改动。

## 实现

- 新增 `src/bootShell.js` 作为 HTML 的轻量入口，不导入 Phaser：先读取自动/手动
  存档存在性，交付“开始游戏 / 继续游戏 / 存档管理”主操作，再在空闲期或用户意图
  后动态加载 `main.js`。
- 标题壳在点击或 Enter/Space `keydown` 后立即锁定意图，24ms 内给出忙碌文案、
  旋转状态和 live region 反馈；加载失败会恢复按钮与原文案并允许重试。
- `BootScene` 接管时复用金句、消费壳层意图，并在同一 JS 任务内完成焦点交接，
  消除旧按钮被删除到新按钮下一帧聚焦之间吞掉键盘输入的空窗。
- 首帧占位在壳层就绪后直接换帧，移除双标题交叉淡化；壳层不再沿用完整菜单
  0.8s 延迟入场，避免“指标已可交互、内容仍透明”的虚高。竖屏增加无额外请求的
  环境光渐变，保留清晰舞台与 47px 主操作。
- Service Worker 升至 `v12-prod`，从 `bootShell → main → 场景 chunk` 递归发现并
  预缓存构建依赖；Phaser 纳入缓存但不读取大包文本做无效递归，保持离线完整链路。
- 首屏性能探针扩展到 Phaser 请求时序、壳层/引擎阶段、点击反馈、离线进入序章与
  1440/1366/1920/390/375/360 六档视口；同步补充壳层失败重试、键盘意图、SW
  两层依赖发现和旧旅程异步契约测试。

## 验证

- 同一 120ms RTT / 250KiB/s 合成弱网下，可交互从 4089ms 降至 525ms
  （-87.2%），可交互前传输从 483980B 降至 123615B（-74.5%）；Phaser 在
  743ms 才发起，标题壳已先可操作。
- 六档视口均在 Phaser/Canvas 出现前显示主操作，按钮高度桌面 52px、手机 47px，
  点击反馈 8–24ms；接管后均为单 Canvas 并进入序章。
- Service Worker 控制后断网重载，标题主操作可见、可用，点击后真实进入序章；
  递归预缓存单测覆盖二层 `main → GameScene/events` 发现。
- 人工复核桌面 1920×1080、1366×768 与手机 390×844、360×800 关键帧：标题、
  金句、忙碌按钮和状态层级清晰，无首帧标题重影、透明假交互或竖屏越界。
- L3：eslint PASS；23 个 unit 文件 / 370 项测试 PASS；production build PASS；
  Playwright 30/30 PASS。最终报告：`.iteration/ui/evidence/R021-verify.json`；性能与
  离线报告：`.iteration/ui/evidence/R021/after/report.json`。
