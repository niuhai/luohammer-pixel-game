# R050 路径可达性与重玩回归

> 日期：2026-08-03 · 类型：全路径 QA / 重玩体验验证 · 触发依据：用户要求验证所有路径可触达、可点击、时序稳定，并检查结局后的再次游玩价值

## 验收范围

- 故事数据图：214 个节点，包含 188 个普通节点与 26 个结局节点。
- 浏览器交互：桌面端与移动端，开场、对话、选择、事件检定、补救、结算、结局和恢复流程。
- 重玩链路：结局页“再来一次”、本局存档清理、元进度保留、新周目差异。

## 发现与修复

- 发现节点切换期间，旧节点的异步场景/人物纹理加载可能晚于新节点完成，从而覆盖当前节点画面。
- 在 `GameScene.loadNode` 与 `_renderNode` 增加渲染请求令牌；旧请求完成时直接放弃，避免迟到渲染造成错图、错文案或错选项。
- 增加全普通节点控件烟测，验证节点进入后存在可见、可点击且至少一个可用的真实按钮。
- 增加结局后的重玩 E2E，验证下一周目会跳过已看过的序章，并出现 `time_traveler` 重玩差异天赋。

## 验证证据

- `validate-story.mjs`：214/214 节点可达；无断链、死路、卡死节点；26/26 结局可达。
- `simulate-paths.mjs`：13 条策略完成，无找不到节点、无可用选项为空、无循环检测或步数超限。
- Playwright：既有核心流程 19/19 通过；本轮路径/重玩/节点控件回归 11/11 通过；节点控件烟测覆盖全部普通选择节点，断言总数 150+。
- Vitest：全量执行仅出现 1 次并发资源超时；对应 `data-integrity.test.js` 单文件复跑 21/21 通过。
- ESLint：0 error / 0 warning。
- Vite production build：通过。
