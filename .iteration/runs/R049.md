# R049 · 剧情绝对可推进保底 + 出租屋背景重制

> 日期：2026-08-01 · 类型：用户实测阻断修复 / 场景质量提升 · 触发依据：用户在 `act0_fail3` 实测认为流程卡死，并指出背景质量过低

## 复现与根因

- 在保存点 `act0_fail3`、AUTO 开启、慢速文字下真实浏览器复现。
- 该节点被拆成 4 段；旧交互需要 8 次“显示全文 / 下一段”推进才出现选项。8 秒观察后仍停在第一段 88/140 字，形成强烈假死感。
- 选择后还有后果确认层；旧探针未确认时节点仍停留在 `act0_fail3`，进一步强化“无法继续”的判断。
- `scene-rental-v2.webp` 是图片生成失败占位图；渲染器另有一份过期硬编码映射，`rental` 即使成功加载也会错误回退为程序化教室。

## 改动

### R049-1：任何长剧情都具备一键逃生口

1. 多段剧情新增清晰的 `直接看选项` 按钮，一次点击停止打字/TTS、清理剩余段落并展示真实选项，不替玩家自动选择、不改变属性。
2. 原 `显示全文` 改为 `显示本段全文`，区分“读完本段”和“跳过剩余剧情”两种动作。
3. 处理 150ms 段落转场竞态：玩家在转场中点击逃生口后，旧延迟回调不会重新挂回打字机。
4. 桌面与手机均使用 ≥44px 控件；逃生口改为高对比金色样式，避免被误认为禁用。

### R049-2：全锁选择的最后防线

1. ChoiceSystem 每轮统一计算条件锁状态。
2. 若数据、存档或组合条件导致所有出口被锁，自动开放第一条存在合法目标的路线。
3. 保底项明确标注 `保底路线 · 避免剧情中断`；点击、数字键、隐藏与销毁生命周期均覆盖。

### R049-3：出租屋背景重制与映射修复

1. 新增可编辑源图 `art-sources/scene-rental-v3.svg` 与发布图 `scene-rental-v3.webp`（2048×1152）。
2. 画面针对本节点重构为雨窗、潮湿脱皮墙面、旧床、矮桌、积水与发霉药材麻袋，不再使用错误教室。
3. PixelRenderer 删除场景纹理的第二份硬编码表，直接从 `SCENE_ASSETS` 建立映射；同时修复 cafe / factory / factory_door 等后加场景潜在的同类回退风险。
4. 新增资源契约测试，阻止出租屋重新指回低体积失败占位图。
